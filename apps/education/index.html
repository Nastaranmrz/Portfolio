My Symposium — Redesign
Interactive prototype

The redesigned intro and sign-in flow, rebuilt from the Figma file on the design’s own grid: splash, app update, onboarding, mobile number and verification code.

Any mobile number starting with 9 works (10 digits). Verification code 1234 signs you in; any other code shows the error state.
